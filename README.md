# AI & Technology Evolution Analysis Using Excel

## 📌 Project Overview

The **AI & Technology Evolution Analysis Using Excel** project explores the growth, adoption and investment trends of different technologies across countries and industries from 2020 to 2026.

This project uses Microsoft Excel to perform data cleaning, data analysis, visualization and dashboard development. An interactive dashboard was created to explore technology adoption patterns and investment trends through PivotTables, PivotCharts and slicers.

**Note:** The dataset contains synthetic practice data created for analytical and dashboard development purposes. The figures are illustrative and should not be interpreted as verified real-world statistics.

## 🎯 Project Objectives

- Analyze technology adoption trends from 2020 to 2026.
- Compare technology adoption across different industries.
- Explore technology adoption across countries.
- Analyze investment distribution among technologies.
- Build an interactive Excel dashboard.
- Present analytical findings through visualizations.

## 📊 Dataset Description

The dataset contains **2,100 records** covering:

- Years: 2020–2026
- Countries: 10
- Technologies: 10
- Industries: 6

### Dataset Columns

| Column Name | Description |
|---|---|
| Record_ID | Unique record identifier |
| Year | Year of observation |
| Country | Country name |
| Region | Geographical region |
| Technology | Technology category |
| Industry | Industry category |
| Adoption_Rate_Percent | Technology adoption rate |
| Investment_USD_Billion | Investment amount |
| Market_Size_USD_Billion | Market size |
| Growth_Rate_Percent | Growth rate |
| Applications | Technology applications |
| Source_Type | Data source classification |
